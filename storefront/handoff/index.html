1Colour theme

Palette is tokenised and every text pair is contrast-checked to WCAG AA. Implement as CSS variables; never hard-code hex in components. Red is reserved for system faults only.

Navy#142548 · --navy

Key rules

  • Amber is a FILL, burnt ink is TEXT — orange CTA buttons use navy text (#142548 on #e87722 ≈ 5.1:1). Orange as text uses #b8460a.
  • Section background rhythm: white → sky tint A → sky tint B → navy accent, so no two adjacent sections share a tone.
  • Star ratings + small orange marks use #b8460a (passes the 3:1 graphic minimum); bright #e87722 only for large fills.

2Typography DM Sans → Poppins

The live store uses DM Sans. The new design uses Poppins for both display and body — rounded, friendly, geometric, matching the brand.

Display / headings — Poppins 800
Hook & Loop Tape
weight 800 · letter-spacing −0.015em · line-height 1.05
Body — Poppins 400 / 600
Industrial hook & loop, dispatched Australia-wide. Volume pricing and a GST tax invoice on every order.
base 17px · line-height 1.6

Implement

  • Font tokens: --font-head / --font-body = "Poppins", "Avenir Next", "Segoe UI", system-ui, sans-serif.
  • Weights used: 400, 600, 700, 800. A .mono utility (system monospace) is used for SKU/spec/data text.
  • Type scale (tokens): hero clamp(2.5rem,4.6vw,4rem) · h2 clamp(1.6rem,3vw,2.4rem) · body 1.0625rem.
Action item: Poppins is referenced in the tokens but no web font is loaded in the prototype. For production, load Poppins (Google Fonts link or self-hosted @font-face, weights 400/600/700/800) or it silently falls back to system fonts.

3Navigation bar

Three tiers: royal-blue promo bar · white logo+search row · royal-blue nav. Nav links are centred; the dropdowns are curated. On scroll the nav pins to the top while the promo strip and logo/search row scroll away — matching the live store. The shot shows the new Industries dropdown open.

Changes to implement

  • Vectorised logo — the store’s master is only 389×69 (blurry on retina). Replace with the crisp SVG (logo-header.svg colour, logo-footer.svg light on navy).
  • Nav bar: royal-blue --blue #1952cc unified with the promo bar; white links rgba(255,255,255,.9), hover pill rgba(255,255,255,.16); links centred.
  • Dropdowns are disclosures, not links — the parent only opens the menu (never navigates). Opens on hover/click/tap/focus; closes on Escape, outside-click, or picking. Chevron rotates 180° when open. Products menu = 8 curated flagship products (not the full list).
  • Header icons: search (mobile → icon that opens search), account, wishlist, cart; badges only show when count > 0. White focus-ring on the blue nav for keyboard users.
  • Sticky nav on scroll — the nav is position:sticky; top:0; the promo strip and logo/search row scroll away above it (mirrors the store's header__stick). An elevation shadow fades in once it's pinned.
  • New “Industries” dropdown — one entry per application/industry guide (see §31) plus an “All industries” index link.

14Animations to add

All motion is 150–300ms, GPU-friendly (transform/opacity only), and respects prefers-reduced-motion.

Motion inventory

  • Hero auto-slider: 4 slides auto-advance every 5s (crossfade opacity 0.6s + slide translateY); the product card scales in 0.97→1; the active progress dot fills over 5s. Pauses on hover/focus; reduced-motion pins slide 1. Grained navy background + a blue spotlight behind the product.
  • Facilities marquee: seamless infinite ticker (two identical rows, translateX(-50%), ~48s linear); pause on hover; reduced-motion → static scrollable row.
  • Product / value / category cards: hover translateY(-4px) + elevated shadow.
  • Nav dropdowns: fade+slide open (0.15s); chevron rotates; state-driven (hover/click/tap/focus).
  • PDP sticky add-to-cart dock: glass panel slides up when scrolled past the CTA, retires before the footer; centred with side-gutters so it clears the corner FABs.
  • Floating buttons: fade/park when the footer is in view (IntersectionObserver).
  • Buttons: hover translateY(-1px); add-to-cart success → green “✓ Added”.
Reduced motion: a global @media (prefers-reduced-motion: reduce) rule near-zeroes all animation/transition durations; the marquee and hero fall back to static frames.
