# Industry / application page images

Drop generated images here and they appear automatically on the pages
(a branded navy gradient shows until then). Naming convention:

- `<slug>-hero.jpg` — page hero image (aspect ~4:3)
- `<slug>-1.jpg` … `<slug>-5.jpg` — the five use-case images, in order (aspect ~16:10)

Slugs:

| Page | slug |
|------|------|
| Clothing & Garments | `clothing-garments` |
| Upholstery & Furniture | `upholstery-furniture` |
| Schools & Education | `schools-education` |
| Signage & Displays | `signage-displays` |
| Automotive, Caravan & RV | `automotive-caravan-rv` |
| Medical & Aged Care | `medical-aged-care` |
| Warehousing & Logistics | `warehousing-logistics` |
| Construction & Industrial | `construction-industrial` |

Example: `clothing-garments-hero.jpg`, `clothing-garments-1.jpg`, … `clothing-garments-5.jpg`.

Generation prompts: see `storefront/handoff/industry-image-prompts.md`.
